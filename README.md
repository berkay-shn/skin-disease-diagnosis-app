# AI-Based Health Diagnosis Mobile App Prototype

This repository contains the source files, documentation, diagrams, and model training materials of my graduation project.

## Overview

The project focuses on developing an AI-powered mobile health application that supports image-based disease prediction, patient appointment management, health data tracking, and healthcare service access.

## Tech Stack

- Flutter / Dart
- Firebase Authentication
- Cloud Firestore
- TensorFlow / Keras
- TensorFlow Lite
- Python

## Project Status

This project was developed as a graduation project prototype. Some components may require additional setup, dependency updates, or Firebase configuration before running successfully.

## Repository Structure

- `mobile_app/` - Flutter mobile application prototype
- `model_training/` - AI model training scripts
- `docs/` - project reports and documentation
- `diagrams/` - system diagrams and design materials

## Note

Firebase configuration files, trained model files, datasets, APK files, and build outputs are not included in this repository.
